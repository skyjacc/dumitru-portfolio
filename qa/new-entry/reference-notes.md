## Точная механика загрузчика

- До первой отрисовки inline CSS блокирует overflow, закрывает весь экран сплошной светлой плоскостью и ставит маленькую фигуру снизу слева. На экране нет процентов, большой типографики или списка ресурсов. См. [index.html:30](</C:/Users/oblako/Desktop/ячс/site_recon/webdesign.kernjosh.com/index.html:30>), кадр `reference-1440-loader.png`.
- Фигура имеет ширину 80 px (70 px до 600 px), пять встроенных WebP-поз. JS атомарно показывает ровно один кадр каждые 200 ms: цикл 1 s. Движение через экран — 69 px/s; длительность вычисляется из реального расстояния до края, при resize сохраняется позиция и направление. См. [index.html:126](</C:/Users/oblako/Desktop/ячс/site_recon/webdesign.kernjosh.com/index.html:126>) и [index.html:183](</C:/Users/oblako/Desktop/ячс/site_recon/webdesign.kernjosh.com/index.html:183>).
- Старт фигуры ждёт decode только пяти её кадров, а не сетевого облачка Loading; есть fail-open 8 s. `prefers-reduced-motion` оставляет статичную позу.
- Фактическая текущая ветка загрузки — **без `[data-loader-fill]`**. В `ee()` ожидается decode предметов сцены, минимальные 2 s для Home, затем зарегистрированные `holdReveal` promises; у зависимостей есть предельные ожидания. Псевдосписок файлов/размеров в том же методе не означает, что такой список виден посетителю.
- Завершение выставляет `body.is-loaded` и `.preloader.is-done`: подложка становится прозрачной, pointer-events отключаются. Спустя 0.6 s фигура получает `is-parked`; она не исчезает вместе с экраном. Ещё позже рядом появляется подсказка Scroll/Swipe. Предметы входят коротким fade + y:14→0, а не разлетаются с резкими скачками.

## Home и переход в Work

Home — одна компактная фраза в пустом центре, обычная фиксированная навигация сверху, фотографические бумажные предметы по краям. Важна свободная центральная область: она уже подготовлена для следующего содержания. На телефоне фраза переносится в две строки; навигация сворачивается в Menu. См. [index.html:307](</C:/Users/oblako/Desktop/ячс/site_recon/webdesign.kernjosh.com/index.html:307>).

`data-work-open` вызывает контроллер `dd()`, зарегистрированный в едином modal registry `ad`. Контроллер сразу ставит `work-open`, активный Work и `aria-hidden=false`; desk API переводит предметы к краям. Через 650 ms overlay получает `is-open` и фокус. Заголовок Home уходит за 0.4 s, предметы переходят за 0.9 s с `power3.inOut`. Управление прокруткой самой Home-сцены на время Work отключается. Закрытие возвращает именно прежнюю композицию Home, а не безусловный начальный пресет; длительность возврата 0.7 s.

**Work показывает одну большую работу и пять точек выбора**, а не одновременно пять карточек. Название, короткое описание, Live-ссылка, роль и стек огибают контур видео; центр содержит реальную запись сайта. Desktop — широкая плоскость, mobile — высокая. Нажатие на превью открывает проект. Для запроса пользователя «все проекты» следует сохранить ясный уровень коллекции, но сделать все пять названий/превью явно доступными; пять безымянных точек референса этот запрос полностью не решают.

Внутри Work есть **второй, отдельный загрузчик**: цветок из восьми кадров для подготовки первого видео. Это не основной загрузчик сайта. См. ## Back и вложенные уровни

Проверенная последовательность на обеих ширинах:

1. Home → Work: появляется коллекция, активируется Work; desktop показывает Back слева от Work, mobile доступен Menu.
2. Work → проект: полноэкранная галерея показывает List/Grid и X. Основная навигация становится inert; нельзя считать её невидимый Back действующей кнопкой этого уровня.
3. Escape закрывает галерею и возвращает прежний выбранный проект в Work.
4. Desktop Back или mobile Menu → Back возвращает Home.

Галерея — собственный вложенный режим, не внешний URL. На всех этих переходах pathname остаётся `/`. Источники: [index.html:384](</C:/Users/oblako/Desktop/ячс/site_recon/webdesign.kernjosh.com/index.html:384>); [work-slider-BQ0ASaXs.js:4161](</C:/Users/oblako/Desktop/ячс/site_recon/webdesign.kernjosh.com/assets/work-slider-BQ0ASaXs.js:4161>), `pg-viewtoggle` offset 546307, `function Cn(` 554357, role/button + клавиатурное открытие `Mt.setAttribute` 555548. ## Что именно создаёт стиль и что исключить

- Предметы выглядят как отсканированные/сфотографированные бумажные вырезки: неровные белые кромки, печатная/фотографическая фактура, небольшая тень от отдельного контура. Это не набор аккуратных векторных пиктограмм и не стерильный 3D desk render. В разметке отдельные `PapierNotebook`, `PapierLaptop`, `PapierFilm`, `PapierSchere` и т. д.; JS клонирует изображение как `.item-shadow`.
- Разные масштабы и повороты выглядят как конкретные разложенные вещи. Края экрана обрезают часть предметов; центр остаётся чистым. Фоновая бумага, тонкое зерно, рукописные акценты и обычный DM Sans составляют одну визуальную систему. Чужие фото, подпись и личные предметы переносить нельзя.
- Базовый hover pill меняет только заливку: `.nav-pill:hover,.nav-pill.is-open` на offset 3199 CSS. Дрожание — **отдельный необязательный модуль `Td()`**, main offset 257291: удары молотка сдвигают всю кнопку x:1.5/y:0.5, случайно разбрасывают буквы Work, затем гасят их. Пользователь уже отверг такое поведение — этот модуль не нужен.
- Отдельно существует idle float предметов: y:3–6 px, rotation ±0.75°, 2.5–4 s, yoyo. Это тоже не обязательная часть перехода Home→Work. About-глаза (`bd`) следят за указателем; сердце (`xd`) пульсирует. Для стабильных кнопок достаточно сохранить active/focus/fill и исключить все эти движения.

## Конкретная адаптация к существующему чёрному пространству

Предлагаемая архитектура, не изменение продукта:

- **Loading** — лёгкая чёрная подложка, собственный маленький знак/штрих и короткий статус; готовность зависит от критичных ресурсов Home. Блокировку снять при успехе или ограниченном fail-open; reduced motion без ходьбы/вращения. Не показывать придуманный процент.
- **Home** — самостоятельное вступление с именем, одним предложением и явным Work; не смешивать Home с уже открытым обзором проектов. Убрать отвергнутую сгенерированную сцену рабочего стола. Если нет исходных фотографий собственных вещей, не имитировать их чужими вырезками или новым искусственным натюрмортом.
- **Work** — переход раскрывает существующую чёрную пространственную доску. Пять реальных проектов получают видимые имена и выбор; это уровень коллекции. Можно использовать уже имеющиеся реальные превью проектов как содержимое, без нового художественного набора.
- **Project** — существующий native viewer и материалы. Возврат должен помнить `originView` и камеру Work. Back из проекта → Work; Back/Home из Work → Home. About/Process открываются над текущим уровнем и возвращают его, сохраняя проверенную камеру. Один переход не должен одновременно принимать скрытые hit targets другого уровня.
- Для текущего кода это означает разделить значение навигации `#work-toggle` (вход в коллекцию) и выбор `#work-list [data-key]` (открыть кейс), а `#home-control` связать с Home-вступлением. Новые Loader/Home состояния не требуют замены native renderer или внедрения Three.js-слайдера референса.
