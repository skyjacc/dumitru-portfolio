## Подтверждённые проблемы и исправления

1. Старые нативные About/Process автоматически загружали невидимые изображения, хотя интерфейс уже использует DOM-композицию. Их загрузка теперь начинается только при явном обращении к старой поверхности. Локализация не запускает ещё не использованные поверхности. Существующие намеренные запросы через API сохранены; адаптер `scripts/adapt-media-loading.cjs` воспроизводит изменения.
2. Быстрый Escape сразу после открытия языкового меню закрывал фото под ним: `aria-expanded` обновлялся позже реального popover. Проверяется фактическое состояние открытого меню. Десять повторов после исправления прошли.
3. Удалённая кнопка Help оставалась в клавиатурном порядке. Теперь скрыта и inert, как остальные старые элементы.
4. Знакомство Home мелькало при открытии проекта из Work. Оно остаётся скрытым во время Detail, включая начало fade.
5. При включении reduced motion зрачки могли остаться смещёнными. Обработчик изменения предпочтения сохраняет новое состояние и возвращает рисунки в нейтральное положение.
6. В коротком горизонтальном окне 568×320 текст About уменьшался до 3,98 px. Тот же телефон теперь поворачивается горизонтально, экран компенсирует поворот; биография 14 CSS px, внутренняя прокрутка, кнопки фото 44 px. Портретные экраны сохранены.
7. Параллельные локальные браузеры получали `ERR_CONNECTION_REFUSED` для части чанков. У Python preview-сервера очередь ожидания была 5. Увеличена до 128 и перезапущен только собственный preview-процесс. Это изменение инструмента разработки, не Vercel-сайта. Неудачные замеры сохранены, итоговые изолированные замеры прошли без ошибок.
